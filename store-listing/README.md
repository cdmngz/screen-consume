## Before publishing

Check the copy and screenshots against the actual release build. Use [README.md](../README.md) for current features, [PRIVACY.md](../PRIVACY.md) for data practices, and [SECURITY.md](../SECURITY.md) for release verification. Do not advertise planned integrations, guarantees of complete history, or features absent from the UI.

Verify that the published privacy-policy URL contains the intended version; local edits are not public until published to the repository. Complete store declarations against the release artifact and current Play Console requirements. Existing draft images need review for current UI, readability, and non-personal data before upload.
