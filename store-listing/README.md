# Google Play listing package

This directory contains the source copy and graphics for the Screen Consume Google Play listing.

## Suggested Play Console settings

- App name: **Screen Consume**
- Default language: **English (United States)**
- App or game: **App**
- Category: **Productivity**
- Contains ads: **No**
- Website: **https://github.com/cdmngz/screen-consume**
- Privacy policy: **https://github.com/cdmngz/screen-consume/blob/main/PRIVACY.md**

Localized listing copy is under `en-US/` and `es-ES/`. Upload the PNG files under `graphics/` to Play Console. Store screenshots are intentionally not fabricated; follow `screenshots/CAPTURE.md` using synthetic or non-personal usage data.
